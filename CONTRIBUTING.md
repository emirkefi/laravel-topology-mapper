# Contributing to Laravel Topology Mapper

Thank you for considering contributing to Laravel Topology Mapper!

## Development & Testing

1. Clone the repository:
```bash
git clone https://github.com/emirkefi/laravel-topology-mapper.git
cd laravel-topology-mapper
```

2. Install dependencies:
```bash
composer install
```

3. Run test suite:
```bash
vendor/bin/phpunit
```

## Pull Request Guidelines

- Ensure all existing tests pass and add unit/feature tests for new functionality.
- Follow PSR-12 coding style guidelines.
- Write meaningful commit messages.
- Update documentation and README.md if public APIs, options, or configuration schemas are altered.
