## Reporting a Vulnerability

Please **do not** report security vulnerabilities through public GitHub issues.

If you discover a security vulnerability within this package, please send an email to Emir Kefi at [your-email@example.com]. All security vulnerabilities will be promptly addressed. 

When reporting, please provide:
* A brief description of the vulnerability.
* Steps to reproduce the issue.
* Any potential impact on the application's network data or infrastructure.

We will try to acknowledge your report within 48 hours and provide a timeline for a patch.
